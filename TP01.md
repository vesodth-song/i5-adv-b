# Tips and Tricks to ensure your code follows PEP 8
-1. [Read the docs](https://peps.python.org/pep-0008/)
0. Realize that code is read more often than written, and consistency may not be paramount if it hampers compatibility.
1. Indentation
   1. Use 4 spaces per indentation
   2. Hanging indents should have no args on the same line as the function, and should use an additional indentation to distinguish it
   3. Spaces are preferred over tabs
2. Limit lines to only 79 characters
3. Do line breaks before binary operators (i.e. keep binary operators on the same line as its right-hand operand)
4. Visual separation
   1. Separate each top-level function and class definitions by two blank lines
   2. Separate class methods by one blank line
5. Source files should always be encoded in UTF-8
6. Importing
   1. Imports should be placed first within a file
   2. Library imports should be on separate lines
   3. Sub-package and package function imports should be on the same line
   4. Imports should be ordered as follows: standard library, third-party, local or library-specific imports
   5. Avoid wildcard imports (i.e. avoid doing `from example import *`)
7. Module-level dunders (ex. `__version__`) should be placed after module docstrings and `from __future__` imports, and before every other imports
8. [Whitespace stuff (and everything else) (I'm not rewriting this here)](https://peps.python.org/pep-0008/#whitespace-in-expressions-and-statements)
